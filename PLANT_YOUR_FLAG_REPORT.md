## 4. Visitor Analytics & Telemetry Engine

To satisfy the free, privacy-friendly analytics requirement with zero reliance on intrusive cookie banners, ThreatLens AI features a dual-layer analytics architecture:

1. **Integrated SOC Telemetry Engine (`analytics.js`)**:
   - **Zero-Cookie Privacy:** Runs entirely in browser storage (`sessionStorage` and local pageview counter) without setting tracking cookies or collecting PII.
   - **Metrics Tracked:** Total Pageviews (PVs), Active Session Duration (heartbeats every 30s), Client Viewport/Device Profile (Mobile vs. Tablet vs. Desktop), Referrer Hostname, and Threat Scanner Execution events.
   - **Live HUD Feedback:** Automatically injects a live telemetry pill into the ThreatLens Status Bar:
     ```
     [ 📈 ANALYTICS: 12 PVs (Desktop) ]
     ```
   - **Developer API:** Exposes `window.ThreatLensAnalytics` with `trackEvent('event_name', metadata)` and `getTelemetry()`.

2. **Cloudflare / Netlify / GoatCounter Drop-in Ready**:
   - For external aggregation, the site is pre-configured to receive Cloudflare Web Analytics or GoatCounter:
     ```html
     <!-- Optional Cloudflare Web Analytics beacon -->
     <script defer src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "threatlens_analytics"}'></script>
     ```

## 6. Custom Domain & HTTPS Setup Guide

For custom domains (e.g., `ravitej.dev` or `threatlens.io`), follow these verified DNS steps:

### Option A: Netlify Custom Domain (Recommended for Zero-Touch HTTPS)
1. Deploy repository `Ravitej555/aiflurency2` on Netlify.
2. In **Site settings > Domain management**, click **Add custom domain**.
3. Point your registrar DNS records:
   - **Apex domain (`@`):** `A` record pointing to Netlify's load balancer IP `75.2.60.5`
   - **Subdomain (`www` or `soc`):** `CNAME` record pointing to `<your-site-name>.netlify.app`
4. Netlify automatically provisions a free Let's Encrypt wildcard SSL certificate within minutes over HTTPS.

### Option B: GitHub Pages Custom Domain
1. In repository settings on GitHub (`Ravitej555/aiflurency2`), go to **Pages**.
2. Under **Custom domain**, enter your domain name.
3. Check the box **Enforce HTTPS** (GitHub will automatically request and renew the TLS certificate).
